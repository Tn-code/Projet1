# 5S Methodology Game 🎯

An interactive learning platform for the 5S methodology (Sort, Set in order, Shine, Standardize, Sustain).

## ✨ Features

- 🔐 **User Authentication** - Login with matricule
- 🌍 **Multi-language Support** - English, Français, العربية
- 🎮 **Interactive Learning** - Click to learn and earn points
- 📊 **Progress Tracking** - Track your learning progress
- 🏆 **Certificates** - Earn a certificate upon completion
- 💾 **Local Storage** - Progress is saved automatically

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
